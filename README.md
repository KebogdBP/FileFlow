# FileFlow M02

Содержит спецификацию, design tokens, UI-компоненты и демонстрационную страницу.

Демонстрация доступна по адресу `http://localhost:3000/design-system` после запуска `pnpm dev`.

M02 включает типографические и responsive-токены, системную/light/dark темы, доступные состояния
фокуса, полный Progress и unit-тесты компонентов.
