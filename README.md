# FileFlow

Privacy-first file conversion and media import workspace.

## Requirements

- Node.js 22+
- pnpm 10+
- Git

## Start

```bash
corepack enable
pnpm install
cp .env.example .env.local
pnpm dev
```

Open `http://localhost:3000`.

## Commands

```bash
pnpm dev
pnpm build
pnpm lint
pnpm typecheck
pnpm test
pnpm format
```

Only the web application is executable in Module M01. Backend and workers are placeholders.
