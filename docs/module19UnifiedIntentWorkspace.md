# M19 — Unified Intent-Based Workspace

M19 turns the existing file and URL entry point into one intent-driven workspace.

## Delivered

- one source flow for images, video, audio, PDF, DOCX and platform URLs;
- local signature inspection before file recommendations;
- a reviewed operation catalog using the exact M16 and M18 backend identifiers;
- category-aware intent choices instead of a fixed single recommendation;
- selectable plans with outcome, execution mode, defaults, privacy and trade-offs;
- explicit review and confirmation state before local or cloud handoff;
- URL import intent review with cloud-worker and quarantine explanations;
- responsive intent controls and keyboard-accessible native buttons;
- preserved mismatch blocking when a file header conflicts with its declared identity;
- the existing local WebP tool remains available inside the same workspace.

M19 owns intent selection and confirmation. Multi-file selection, grouped execution and batch
progress belong to M20.
